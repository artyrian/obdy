# Bundled vehicle profiles

`Ford-Mustang.json` is the signal set from [OBDb/Ford-Mustang](https://github.com/OBDb/Ford-Mustang)
(commit `85b7a2d`, 2026-11-24), bundled so the Mustang works offline.

It is © OBDb editors and contributors, licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); changes to it must be shared under the same license.
It is unmodified here.

Other cars load their profile from OBDb on GitHub on first connect and are cached in the browser.
